## 🌟 The 5 Pillars of the Ecosystem (Captain Planet Metaphor)

Like the five rings that combine their powers to create Captain Planet, this repository unifies five distinct fields of technology, health, and engineering into a single harmonious ecosystem:

* 🪨 **Earth (Hardware):** **Smart Orthopedic Insole** — ESP32-C3 firmware, FSR-402 pressure sensors, MOSFET drivers, and active magnetic damping for plantar fasciitis relief.
* 🔥 **Fire (Energy):** **Embedded Caloric Balance Panel** — Interactive web tool tracking metabolic rates (TMB), daily activity, and caloric deficit transformation.
* 🥗 **Water (Nutrition):** **D5 Culinaria & Life Strategy** — Real-life transformation methodology from 137 kg to 100 kg using clean, simple, and functional nutrition.
* 🌬️ **Wind (Biometrics):** **Heart Rate & Stress Monitoring** — Processing real-time physiological indicators (BPM and stress index 0-100).
* 🩵 **Heart / 5th Element (Poetic AI):** **Soul Biometric Synthesizer ("Irmãzinha" IA)** — Decision Tree algorithm and Python Flask API delivering empathetic, emotional, and poetic responses based on physiological states.

## 🚀 Architecture & Tech Stack

* **Front-end:** HTML5, CSS3 (Dark/Gold Theme), JavaScript (`fetch` API).
* **Back-end:** Python with **Flask** micro-framework and **CORS**.
* **Intelligence:** Supervised Learning / **Decision Tree Classifier** (`scikit-learn`).
* **Hardware & IoT:** ESP32-C3, FSR-402 Pressure Sensors, PWM MOSFET Drivers.
